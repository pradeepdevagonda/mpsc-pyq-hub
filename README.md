# MPSC PYQ Hub

GitHub Pages-ready MPSC Previous Year Question Paper website.

## Main sections
- Rajyaseva
- Combined Group B
- Combined Group C
- PYQs
- Syllabus
- Exam Pattern
- Resources

## Add PDFs
Put each PDF inside the matching `pdfs/<exam>/<stage>/<year>/` folder.

Example:
`pdfs/rajyaseva/prelims/2025/gs-paper-1.pdf`

Then add the PDF metadata to the `papers` array in `index.html`.

## GitHub Pages
Upload the complete project to the GitHub repository and enable Pages from:
Settings → Pages → Deploy from branch → main → / (root)
